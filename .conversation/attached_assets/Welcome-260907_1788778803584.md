# 📚 DIGITAL LIBRARY — SMAN 1 BUKITTINGGI

### *Modern Library Experience • Clean • Friendly • Accessible*

---

## 1. 🎯 Konsep Utama

**Core idea:**

> **“Find it. Read it. Grow with it.”**

Website perpustakaan bukan dibuat seperti sistem administrasi, tapi sebagai **digital gateway ke seluruh koleksi perpustakaan sekolah**.

### Target pengguna

* 👨‍🎓 Siswa
* 👩‍🏫 Guru
* 👨‍💼 Pustakawan
* 👨‍👩‍👧 Pengunjung umum

### Prinsip desain

| Prinsip    | Implementasi                                  |
| ---------- | --------------------------------------------- |
| Modern     | Layout editorial, whitespace, typography kuat |
| Clean      | Tidak terlalu banyak card/elemen              |
| Friendly   | Bahasa sederhana, CTA jelas                   |
| Accessible | Kontras tinggi, ukuran teks nyaman            |
| Fast       | Optimasi gambar & lazy loading                |
| Responsive | Mobile-first                                  |
| Consistent | Satu design system                            |

## Typography

**Primary font:** Inter
**Alternative:** Satoshi

Hierarchy:

```text
Display
56–64px / Bold

H1
40–48px / Bold

H2
30–36px / Bold

H3
22–24px / Semibold

Body
16px / Regular

Small
14px
```

---

## UI Style

* Border radius: **12–20px**
* Button radius: **10–12px**
* Card radius: **16px**
* Soft shadow, jangan berlebihan
* Icon: Lucide / Phosphor
* Animasi: subtle, 150–300ms
* Hover: transform kecil + perubahan elevation

**Jangan:** glassmorphism berlebihan, gradient di mana-mana, 20 jenis warna, atau animasi yang bikin perpustakaan terasa seperti website crypto 😭

# 18. 📱 RESPONSIVE BREAKPOINT

### Desktop

`≥ 1024px`

Navbar lengkap, sidebar filter, multi-column grid.

### Tablet

`768–1023px`

Navbar lebih compact, filter bisa collapse.

### Mobile

`<768px`

Bottom/compact navigation atau hamburger.

Book grid:

```text
Desktop → 4 columns
Tablet  → 3 columns
Mobile  → 2 columns
```

Hero juga harus dipadatkan supaya **nggak menghabiskan satu layar penuh cuma buat banner**.

# 19. ✨ MICRO-INTERACTION

Sedikit saja, tapi terasa hidup.

### Hover book

Cover naik sedikit:

`translateY(-4px)`

### Button

Subtle scale:

`scale(1.02)`

### Search

Focus → border/highlight berubah.

### Page transition

Fade/slide pendek.

### Loading

Skeleton:

```text
┌──────────┐
│ ░░░░░░░░ │
│ ░░░░░░░░ │
└──────────┘
```
